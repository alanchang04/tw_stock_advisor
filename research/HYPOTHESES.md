# 假說登記簿（Research V2）

> 規範：`docs/RESEARCH_V2_PIPELINE.md` §4
> 驗收流程：`docs/STRATEGY_VALIDATION_PROTOCOL.md`

**規則**

1. **跑第一行程式之前**先在這裡加一列。事後補登一律標 `(補登)`。
2. 「假說來源」欄決定哪段資料還能用——若來自回測挖掘，那段資料就不能再當驗收集合。
3. 「所需資料」必須註明**該資料在目標期間是否存在**。這一欄是 REV-1B 與
   布林 Chip 因子的死因，不可略過。
4. 「型態」決定獨立樣本數要用情境聚合還是 block bootstrap（§3）。
5. 結論欄只能填 **採用 / 否決 / 待驗**。

## H01 — 布林二次突破（Volatility expansion + re-breakout）

| 欄位 | 內容 |
|---|---|
| **機制** | 第一次帶量突破上沿代表新資訊進場、趨勢啟動。回落至通道內是獲利了結與換手。第二次突破時，追價者已進場完畢，最後一批買方是看到型態才進來的散戶——他們沒有資訊優勢、部位小、停損近。對手方是刻意在此製造價格的大戶：**若大戶同步增加持股＝換手後續攻；若大戶減碼＝拉高出貨**。因此第二次突破本身不帶方向，方向由「誰在接」決定。 |
| **假說來源** | 使用者看盤觀察（**非**回測挖掘）→ 依 PIPELINE §6，全部歷史資料可用 |
| **事件定義** | BB(20, 2σ)；帶寬 >過去 60 期中位數；成交量 ≥20 期均量；狀態機：突破上沿→收盤回到帶內→再次突破上沿。週 K 定 regime、日 K 抓進出場。 |
| **所需資料** | 價量 ✅ 2015~ 完整／法人買賣超 ✅ TWSE 2015~、TPEX 2018~／**TDCC 大戶持股 ❌ 免費源僅當週，無歷史** |
| **型態** | **連續橫斷面**（實測 2,714/2,812 個交易日都有訊號）→ 用 block bootstrap，**不可**用情境聚合 |
| **預計試驗次數** | 待定，下限 12（5 單因子分位 + 4 ablation + 3 baseline） |
| **失敗條件** | Phase 2 的 CAR 在 5/10/20/40/60 日全部不顯著；或 Phase 3 的 Random baseline ≈ Full ranking |
| **結論** | **待驗**（尚未凍結，尚未執行任何回測） |

**已知地雷（2026-08-13 實測）**

1. **Chip 因子必須改用法人買賣超。** TDCC 免費源只給當週，10 年歷史要付費；
   `tdcc_fetcher.py` 檔頭 2026-07-26 已判定「現在無法做嚴謹回測因子研究」。
   法人買賣超反而更適合：**日頻**、且分外資／投信／自營，直接回答「誰在接」。
2. **訊號不具選擇性。** 每日觸發中位數 20 檔、p90 44 檔、最多 164 檔。
   決定報酬的是排序規則，不是布林。必做 §2 Phase 3 的三組 baseline。
3. **週 K 循環太長不可直接交易。** 循環長度中位數：日 K 25 個交易日、
   **週 K 19 週**（p75 40 週）。週 K 只能定 regime。
4. **Pullback duration 需要事前固定的上限。** 第一次突破後 60 期才二次突破，
   是否仍算同一個 setup？未定義會讓事件母體失控。

## H02 — 機構確認（H01 的交互作用）

| 欄位 | 內容 |
|---|---|
| **機制** | 同 H01。第二次突破時若法人（投信／外資）同步買超，代表有資訊方承接；若法人賣超而散戶追價，代表出貨。 |
| **假說來源** | 同 H01 |
| **事件定義** | H01 事件 × 法人買賣超變化量（`ΔNet`，非絕對值） |
| **所需資料** | 法人買賣超 ✅ TWSE 2015~ |
| **型態** | 連續橫斷面 |
| **結論** | **待驗**（依附 H01，H01 未過不執行） |

用變化量而非絕對值：台積電與小型股的法人結構天生不同，絕對值不可橫斷面比較。

## H03 — 假突破（H01 的反向）

| 欄位 | 內容 |
|---|---|
| **機制** | 第二次突破但法人減碼、或爆量而價格未推動（大量換手＝上方賣壓巨大），應呈現顯著較差的 forward return。 |
| **假說來源** | 同 H01 |
| **事件定義** | H01 事件 × 低 Price-Volume Efficiency × 法人賣超 |
| **所需資料** | 價量 ✅／法人 ✅ |
| **型態** | 連續橫斷面 |
| **結論** | **待驗** |

H03 是 H01 的**否證設計**：若 H01 成立但 H03 不成立（好壞事件無差異），
代表排序因子沒有資訊量，H01 的 edge 可能只是市場 beta。

## 候選排序因子池（上限 10 個，第一輪不得全用）

| 類型 | 因子 | 市場意義 | 資料 |
|---|---|---|---|

| Trend | MA20 slope | 趨勢方向 | ✅ |

| Volume | `Volume/MA20(Volume)` | 參與度 | ✅ |
| Volume | Price-Volume Efficiency | 同一單位量能推動多少價格 | ✅ |
| Pattern | Pullback depth / ATR | 洗盤幅度（預期有 sweet spot，非越淺越好） | ✅ |
| Pattern | Pullback days | 整理時間 | ✅ |
| Chip | 法人 ΔNet | 機構確認 | ✅ 2015~ |
| Chip | ~~Δ大戶持股~~ | ~~籌碼集中~~ | ❌ **無歷史，本輪不用** |

第一輪建議只用五個：60 日相對強弱、CLV、Pullback depth/ATR、
Price-Volume Efficiency、法人 ΔNet。

## H01 — 布林二次突破（Volatility expansion + re-breakout）

| 欄位 | 內容 |
|---|---|
| **機制** | 第一次帶量突破上沿代表新資訊進場、趨勢啟動。回落至通道內是獲利了結與換手。第二次突破時，追價者已進場完畢，最後一批買方是看到型態才進來的散戶——他們沒有資訊優勢、部位小、停損近。對手方是刻意在此製造價格的大戶：**若大戶同步增加持股＝換手後續攻；若大戶減碼＝拉高出貨**。因此第二次突破本身不帶方向，方向由「誰在接」決定。 |
| **假說來源** | 使用者看盤觀察（**非**回測挖掘）→ 依 PIPELINE §6，全部歷史資料可用 |
| **事件定義** | BB(20, 2σ)；帶寬 >過去 60 期中位數；成交量 ≥20 期均量；狀態機：突破上沿→收盤回到帶內→再次突破上沿。週 K 定 regime、日 K 抓進出場。 |
| **所需資料** | 價量 ✅ 2015~ 完整／法人買賣超 ✅ TWSE 2015~、TPEX 2018~／**TDCC 大戶持股 ❌ 免費源僅當週，無歷史** |
| **型態** | **連續橫斷面**（實測 2,714/2,812 個交易日都有訊號）→ 用 block bootstrap，**不可**用情境聚合 |
| **預計試驗次數** | 待定，下限 12（5 單因子分位 + 4 ablation + 3 baseline） |
| **失敗條件** | Phase 2 的 CAR 在 5/10/20/40/60 日全部不顯著；或 Phase 3 的 Random baseline ≈ Full ranking |
| **結論** | **否決**（2026-08-13，見下方 Phase 2 結果） |

### ⚠️ 重大更正（2026-08-13 晚）：先前測錯了事件

使用者以標註圖指出，其策略是**第一次突破（B1）買進、第二次突破（B2）賣出**。
但規格 §3 寫的是「受測事件是 B2」，因此先前測的是**賣出之後**的報酬——
那不是這套策略。**這是規格撰寫時的漂移，不是使用者描述不清。**

更正後的兩次測試與一個被抓到的嚴重 bug：

**第一次更正嘗試（含前視偏誤，已作廢）**：只取「後來確實出現 B2」的 B1，
得到 60 日超額 +8.35%、勝率 78%、p=0.000。**這個數字是錯的**——B2 的定義是
「價格再次突破上沿」，若第一次突破後一路下跌就永遠不會有 B2，那些交易
從樣本中消失。**出場條件用到了未來資訊。**

**第二次更正（無前視，正式結果）**：取**所有** B1，不論後續有無 B2。

| 窗 | 含前視（作廢） | **無前視（正式）** | p |
|---|---:|---:|---:|
| 5 日 | +1.66% | +0.104% | 0.368 |
| 10 日 | +3.05% | +0.326% | **0.028** |
| 20 日 | +5.13% | +0.383% | 0.106 |
| 40 日 | +7.40% | +0.797% | **0.048** |
| 60 日 | +8.35% | +1.041% | 0.072 |

**前視偏誤把效果放大了約 8 倍。**

### 平均為正、中位數為負——這是本次最重要的發現

59,392 個 B1 中有 14,417 個通過 universe＋週 K 多頭濾網。60 日窗分布：

| 統計量 | 值 |
|---|---:|
| 平均 | **+1.041%** |
| 中位數 | **-4.700%** |
| 勝率（超額 > 0） | **39.5%** |
| p5 | -28.45% |
| p95 | +48.41% |
| p99 | +110.63% |
| **前 5% 交易佔總和** | **438%** |

**六成的交易輸給「隨機挑一檔合格股票」，中位數輸 4.7%。**
平均之所以為正，完全來自右尾——前 5% 貢獻了總和的 438%，
意思是**拿掉它們，總和是負的**。

這與現行波段策略的形狀完全一樣（475 筆交易中 10 筆佔 96% 淨利）。

### 這解釋了「為什麼實戰感覺有用」

三件事同時為真：

1. **那些跑很大的案例是真的**（p99 = +110%），而且視覺上非常鮮明、容易記住
2. **但十次有六次是輸的**，中位數還輸給隨便買一檔
3. 你實戰不會每個訊號都做——**你的判斷（趨勢背景、族群、題材）可能才是 edge**，
   而它不在機械規則裡

### 決定性的一點：edge 與交易成本同級

60 日平均超額 **+1.041%**，而台股一次完整換手成本：

| 項目 | 成本 |
|---|---:|
| 證交稅（賣出） | 0.300% |
| 手續費（雙邊，未折） | 0.285% |
| 滑價（規格假設 30bp 雙邊） | 0.600% |
| **合計** | **1.185%** |

**+1.041% − 1.185% = −0.144%。** 即使手續費打折、滑價壓到 10bp 雙邊
（合計約 0.62%），淨值也只剩 +0.42%／60 日，約年化 +1.7%。

**這個 edge 的大小與交易成本同一個量級**，這才是它不可部署的真正理由，
而不只是「p 值不夠小」。

### 判決：維持否決，但理由更新

依規格 §6，通過需「至少 3 個窗顯著為正」→ 實得 **2 個**（10 日、40 日）。
仍未達標，但**比先前測錯事件時的 0/5 好得多**。

更關鍵的是成本分析：即使把統計門檻放寬到 2/5 算通過，
扣掉交易成本後也所剩無幾。**否決的主因由「統計不顯著」改為「edge 不覆蓋成本」。**

### 若要重啟，正當的方向只有兩個

1. **改善出場**（Phase 5）。目前是固定窗；分布右尾極厚（p99 +110%）而左尾也厚
   （p5 -28%），這正是「截斷左尾、放大右尾」最可能有價值的形態。
   但那必須先過 Phase 2，不能倒過來用出場救進場。
2. **改善選股**（Phase 3）。每日 20 檔觸發、只能買 10 檔，排序規則若能把
   前 5% 的贏家挑出來，價值遠大於調整進場門檻。

**不得**做的：調 BB 參數、收緊帶寬或量能門檻、或用其他濾網把樣本篩到剛好顯著。

### 判決：否決

依規格 §6 的**凍結**驗收標準：

- 通過需「至少 3 個窗的 CAR 顯著為正」→ 主檢定 **0 個**顯著
- 否決條件「所有觀察窗的 CAR 皆不顯著」→ **成立**

**機制本身也被否證。** 假說是「第二次突破＝跟風者耗盡＝反轉」，
若成立，上沿應轉弱、下沿應反彈。實測是：

- 上沿：與「隨機挑一檔合格股票」**無異**（主檢定全不顯著）
- 下沿：**顯著繼續下跌**（10~60 日 p<0.05），是**延續**不是反轉

也就是說第二次跌破下沿**不是「賣太多了」，而是還會再跌**。方向與假說相反。

### 為什麼主檢定選等權是對的

| 基準 | 2015~2026 總報酬 |
|---|---:|
| 等權 universe | +339.0% |
| 0050 含息 | +773.5% |

若只用 0050 當基準，多側會得到「顯著為負」的結論——但那**其實是規模效應**：
訊號選出的股票表現與平均個股無異，而該期間大型股大幅贏過中小型股。
用等權基準才能把選股 alpha 從規模效應中分離出來。這是規格 §8.2 事前裁決的價值。

### 誠實記錄：多側方向為正但不達標

多側 CAR 路徑**單調遞增不回吐**（-0.15% → +0.83%），60 日 p=0.12。
方向不是零，只是**不足以宣稱**。依凍結標準這是否決，
**不得因為「看起來有一點」就放寬門檻或加濾網重測**（PIPELINE §6）。

若日後要重啟，唯一正當的理由是**改用真正的 PIT universe**（見下方限制），
而不是調參數。

### 本次執行修掉的一個嚴重 bug

首次執行時基準只做除權息還原、未做分割還原。0050 在 **2025-06-18 有一次
+74.78% 的分割**且不在 `dividend_events` 內，導致任何跨越該日的窗格產生假的
負超額。修正前 0050 全期總報酬算出 +120.3%，修正後 +773.5%（回測記載 +767.6%）。
空側 60 日窗因此從 +4.48%(p=0.45) 變為 -2.43%(p=0.04)。

**已知地雷（2026-08-13 實測）**

1. **Chip 因子必須改用法人買賣超。** TDCC 免費源只給當週，10 年歷史要付費；
   `tdcc_fetcher.py` 檔頭 2026-07-26 已判定「現在無法做嚴謹回測因子研究」。
   法人買賣超反而更適合：**日頻**、且分外資／投信／自營，直接回答「誰在接」。
2. **訊號不具選擇性。** 每日觸發中位數 20 檔、p90 44 檔、最多 164 檔。
   決定報酬的是排序規則，不是布林。必做 §2 Phase 3 的三組 baseline。
3. **週 K 循環太長不可直接交易。** 循環長度中位數：日 K 25 個交易日、
   **週 K 19 週**（p75 40 週）。週 K 只能定 regime。
4. **Pullback duration 需要事前固定的上限。** 已於規格 §3.1 定為 60 期。
5. **universe 非 PIT。** PIT security master 只覆蓋 2005~2014，2015~2026 沒有
   對應元件，本次以「四位數代號」近似普通股。這是本次研究最大的方法限制，
   也是日後唯一正當的重啟理由。

## H04~H06 — 現行策略殘存因子的重新驗證

現行波段策略已封存不再調參（`RESEARCH_V2_PIPELINE.md` §1），但其中三個因子
在 P1 十年因子研究中證據相對較強，值得用 Phase 2 的正確方法重新檢驗。

**這三個的處境與 H01 完全不同，必須先講清楚。**

### 為何不能像 H01 那樣自由使用 2015~2026

| | H01 布林 | H04~H06 |
|---|---|---|
| 假說來源 | 看盤觀察 | **2026-07-19 P1 因子研究（2015~2026 資料）** |
| 依 PIPELINE §3.1 決策樹 | 走右邊：全部資料可用 | **走左邊：該段資料已污染** |

而且更麻煩：**乾淨期間根本沒有這些資料**。release `tw_stock_data_2005_2014_r2`
的九個元件裡沒有 `monthly_revenue`、也沒有 `institutional`；本機這兩份都從
2015-01 才開始。

**所以 H04~H06 沒有任何可用的 backward 驗收期間。** 這與 REV-1B 死於融資餘額
是同一種處境。

### 但仍值得做：污染資料可以否證，不能確認

這是 §9.2 F1 重新定位的同一個邏輯，套用到因子層：

| 結果 | 可以宣稱 | 不可以宣稱 |
|---|---|---|
| 效果**消失** | 該因子被否證，正式除役 | — |
| 效果**存活** | 「在正確方法下沒有被否證」 | ❌「有效」 |

P1 的舊研究有 `SPEC_DATA_FOUNDATION_AND_MOMENTUM.md` §1.3 記載的五項方法缺陷，
其中兩項會**系統性高估**顯著性：

1. 因子在收盤後才完整可知，舊報告卻**從同日收盤**計 forward return
   → 必須改為 T+1 可成交價
2. 20/60/120 日 forward return 大量重疊，把每日 IC 當獨立樣本算 t-stat
   → 必須改用 Newey-West、非重疊抽樣或 block bootstrap

**若某個因子在修正這兩項後就消失，那是真實的負面結果，且立刻省下 12 個月的
forward paper。** 這就是做它的理由。

### 事前登記的因子清單（一次跑完，不得事後追加）

|---|---|---|---|
| 1 | 60 日相對強弱 | 強者恆強 | ✅ |

### 檢定方法

- 因子值一律取**同一事件日內的橫斷面百分位**，不用原始值
  （原始值會讓極端值支配）
- 每個因子單獨看 **Q1~Q5 分位的 forward 超額報酬單調性**
- 同時算 **RankIC**（Spearman），報 mean IC / IC std / **ICIR**
- **單調性比 ICIR 大小重要**：單調關係比較像真實市場結構

### 試驗次數

本輪固定 **8 次**：5 個單因子 + 3 組 baseline（Random／Signal-only／等權組合）。
Random baseline 的 1,000 次 Monte Carlo 算 1 次。

**不得**在本輪掃描因子參數（如把 RS60 改成 RS20 再試）。

### 決定性檢定：選股到底有沒有增益

**先前的比較方法是錯的並已作廢。** 我原本拿「完整排序的點估計 +0.490%」
去比「隨機選股的 Monte Carlo 分布 [+0.22, +0.33]」，看似打贏——
但那兩個數字的樣本基礎不同，而且我沒有計算完整排序自身的抽樣誤差。

正確做法是**同一批日期的配對比較**：每日「前 10 名平均 − 全候選平均」，
再對這個逐日差異序列做 block bootstrap。

| 窗 | 可比較日數 | 選股增益 | 95% CI | p |
|---|---:|---:|---|---:|
| 20 日 | 545 | +0.089% | [-0.134%, +0.305%] | 0.438 |
| 60 日 | 543 | +0.229% | [-0.200%, +0.733%] | 0.330 |

**排序沒有帶來可辨識的增益。**

### 一個推翻前提的發現

1,805 個相異事件日中，**只有 545 天（30%）的候選數 >= 10**。

也就是說**七成的訊號日根本沒有選擇問題**——候選不足 10 檔，全買就是了。
先前引用的「每日中位數 20 檔」是**未套用週 K regime 與 universe 濾網前**的
原始 B2 訊號數，套完濾網後稀疏得多。

Phase 3 的前提是「觸發檔數 > 可持有檔數」，這個前提在七成的日子並不成立。

### 判決：否決

三個證據一致：單因子全不單調、ICIR 全為雜訊、配對檢定無增益。
**布林候選之間沒有可辨識的橫斷面 alpha。**

依 PIPELINE §2.1 的防濫用規定，H01 的否決**不因本輪而撤銷**，
且本輪不得改因子重跑。若日後要重啟，須提出**新的機制假說**，
而不是換一組技術指標再掃一次。

而投信連買可以在同一波行情裡反覆達標。

### 二、M4 逐年刪除：事件研究的正面結果全部由 2025 撐起

| 事件集（120 日、0050 基準） | 平均 | 拿掉 2025 | 變號 |

### 三、M13：一個自查抓到的存活者偏差（先講這個，因為它改變下面所有數字）

第一版面板把同一個「已套用流動性遮罩」的報酬矩陣同時當成決策時點的橫斷面

——而掉出門檻的多半是跌下去的那些。

| 因子（6M） | 規格 | 含偏差 | 修正後 | 差 |
|---|---|---:|---:|---:|

規格：**只留當月有月營收申報者（排除 ETF）、控制規模、前瞻報酬不套未來條件**。
結果檔 `research/results/fama_macbeth_operating_only.json`。

| 因子 | M+1 | M+2 | M+3 | M+4 | M+5 | M+6 | 6M 累積 |

| 月營收 YoY>0 | +0.936 | +0.776 | +0.477 | +0.284 | +0.065 | +0.017 | **+2.44%**（t=5.08） |
| 月營收 YoY>20% | +0.824 | +0.686 | +0.436 | +0.173 | -0.223 | -0.203 | **+1.77%**（t=3.03） |

月營收兩條**逐月遞減、第五個月歸零**——資訊擴散應有的形狀。
三條都通過 M4 逐年刪除稽核（12 個年度無一刪掉會變號）。

同一套逐年稽核**殺掉了事件研究層級的結果**（月營收 +2.836% → 拿掉 2025 變 -1.170%），
卻沒有殺掉 Fama-MacBeth 的結果。差別在於 FM 每個月等權貢獻一個係數，
少數極端個股會被該月的橫斷面平均掉。

**兩個反直覺結果**：

1. **投信連買的路徑是平的、不衰減**。那不是事件反應的形狀，
   比較像持續性的特徵曝險。同樣顯著為正，**機制證據遠弱於月營收**。
2. **多空價差的大小不等於可部署性**，見下一節——排序會反過來。

|---|---:|---:|
| 月營收 YoY>0 | +2.67%（t=4.20） | +2.44%（t=5.08） |

### 六、M2 多重檢定：那個「唯一顯著」不構成證據

三輪研究實際檢視過 **56 格**，α=0.05 下期望誤報 **2.8 格**。
觀察到 1 格顯著（H09 多頭排列 5 日），**少於純雜訊的期望值**。

## 可部署性：多空價差會把排序弄反

Fama-MacBeth 的係數是**多空價差**，不是任何人拿得到的報酬。
能部署的是「買進有訊號者、相對於買進全體」，關係是
`long_only = (1 − p) × b`（p ＝ 當期有訊號的比例）。

**因此選擇性高的訊號，即使多空價差較小，只做多的超額報酬反而可能較大。**

只做多、持有 4 個月（效果集中的期間）、扣一次 1.185% 完整換手成本。
**多空欄位在此改用未控制規模的規格**，與只做多同口徑——實際下單時
規模傾斜會原封不動跟著進來，無法「控制掉」：

| 因子 | 多空 6M | **只做多 4M** | 訊號比例 | **扣成本後** |
|---|---:|---:|---:|---:|
| 月營收 YoY>20% | +2.02% | **+1.65%** | 30.9% | **+0.46%** |
| 月營收 YoY>0 | +2.67% | +1.04% | 61.4% | **-0.14%** |
| 投信連買 | +2.50% | **+1.50%** | 27.5% | **+0.32%** |

**排序完全反過來了。** 多空價差最大的 `rev_yoy>0`，只做多反而是唯一負的
——因為它把 61% 的股票都標成訊號，選擇性太低。

**這推翻了本文稍早「`>0` 比 `>20%` 強，`rev_accel` 除役」的說法。**
作為橫斷面因子 `>0` 的價差確實較大，但作為可部署的組合 `>20%` 明顯較好。
`rev_accel` 不除役。

### 兩個層次要分開講

| | 月營收 YoY>20% | 月營收 YoY>0 | 投信連買 |
|---|---|---|---|
| **作為橫斷面因子** | 未被否證 | 未被否證 | 未被否證 |
| **作為可部署策略** | **否決** | **否決** | **否決** |

三個因子的只做多 4 個月超額報酬都在 **2.185% 的經濟門檻之下**
（最高 +1.65%），扣成本後剩 −0.14% ~ +0.46%，年化約 −0.4% ~ +1.4%。

**統計上是真的，經濟上約等於零。** 這兩件事必須同時說，
只講前者會誤導成「找到有效因子」，只講後者會丟掉一個真實的發現。

1. **不等於「有效」。** 假說源自 2015~2026 的 P1 因子研究，該段資料已污染；

# H11~H15 — 基本面 → 法人確認 → 價格時機（分層假說鏈）

> 登記日：2026-08-14
> 來源：外部審閱提出的架構，加上本專案的三項補充（試驗預算、資料可用性、已知結果）
> 狀態：**僅登記，尚未執行。** 依 `RESEARCH_V2_PIPELINE.md` §4，登記與執行分開。

## 為什麼這條線與舊策略不同

舊策略是把所有指標放進同一層加分：

```
Score = Revenue(30) + Trust(25) + MA(10) + BB(10) + RSI(5) + …
```

問題不在權重，在於**這些東西本來就不是同一種類的判斷**：

| 層 | 回答的問題 |
|---|---|
| 基本面 | 買誰？ |
| 法人流 | 市場是不是正在認同？ |
| 價格／量能 | 現在是不是進入反映階段？ |
| 出場 | 原本的理由是否失效？ |

把它們攤平成加分題，等於假設「營收好 3 分」和「站上均線 3 分」是可互換的。
分層之後每一層都可以獨立被殺掉，這才是分層的價值。

## 機制敘述（Layer 1 的正確寫法）

**不是**「營收成長 ⇒ 股價上漲」。中間至少少了三層：

```
Revenue × Margin − Expenses + NonOperating ⇒ NetIncome
EPS = NetIncome / Shares
Price = EPS × PE
```

所以可能出現：營收 +30% 但毛利率由 25% 掉到 15%，EPS 未必增加；
或 EPS +30% 但市場原本預期 +60%，股價照跌；
或 EPS +30% 但 PE 由 30× 降到 20×，股價還是跌。

**因此真正的命題是**：

> 企業營運出現持續性改善後，市場未必一次完全反映其對未來盈餘的影響，
> 因此價格可能在數月內逐步重新評價（gradual price discovery / underreaction）。

## 全鏈的資料與污染狀態（先看這個，決定了能宣稱什麼）

## H12 — 法人確認的交互作用

| 欄位 | 內容 |
|---|---|
| **機制** | 營收是**資訊**，法人流是**市場確認**。營收好但法人無動作，可能代表已 priced-in、營收品質不佳、或產業前景不支持；營收好且法人持續建倉，代表基本面改善正被專業資金認可。 |
| **假說來源** | P1 因子研究（污染） |
| **受測對象** | **交互項** `Revenue × InstitutionalConfirmation`，**不是**兩者相加 |
| **所需資料** | 月營收 ✅ 2015~／法人 ✅ TWSE 2015~；乾淨期間 ❌ |
| **型態** | 事件驅動 |
| **結論** | **否決**（2026-08-14，見下方執行結果） |

### 主要估計式改為「Revenue=1 條件迴歸」，不是交互項（2026-08-14 修正）

原登記寫的是交互項 `Revenue × Confirm`。改掉，理由有二：

**一、交互項的係數會被讀錯。** 四組的期望報酬貢獻是

| Revenue | Confirm | 貢獻 |
|:--:|:--:|---|
| 0 | 0 | 0 |
| 1 | 0 | β_R |
| 0 | 1 | β_C |
| 1 | 1 | β_R + β_C + β_RC |

所以「法人確認對營收股的增益」是 **β_C + β_RC**，不是 β_RC 單獨。
把 β_RC 當成增益是常見誤讀。

**二、條件迴歸自由度更低、也更貼近真正的問題。** 我們要問的不是
「乘積係數顯不顯著」，而是「在已經有營收訊號的股票裡，再看到投信確認，
未來報酬是否更好、好多少」。那就是

> **樣本限制在 `Revenue = 1`**，逐月跑
> `r[i,t+1] = α[t] + β[t]·Confirm[i,t] + γ[t]·Size[i,t] + ε`，
> 再對 `β[t]` 序列做 Newey-West。

2×2 完整迴歸（含交互項）列為 **robustness check**，不是主要檢定。

### landmark design：本假說最危險的地方（M15）

「營收公布後 20 個交易日內投信累計買超 100 張」這個條件，
**在營收公布當日並不知道**。若一邊用那 20 天決定 `Confirm`、
一邊把那 20 天的報酬算進績效，就是前視。

```
營收事件
   │
   ├──── 20 個交易日：觀察投信 ────┐
   │                               │
                            decision date
                        （此刻 Confirm 才確定）
                                   │
                                   ▼
                      前瞻報酬自此之後才起算
```

實作一律經過 `research.policy:landmark_confirmation`，
並以 `assert_information_precedes_decision` 守門——
`forward_start <= information_end` 直接拋錯。

### 事前登記的唯一定義（不得事後更動）

「法人確認」在本輪**只有一個定義**，且刻意沿用既有已凍結的參數，不新增自由度：

> 自營收 decision date 起算的 **20 個交易日**內，投信累計買超達到 **100 張**
> （沿用 `agent/strategy.py::MIN_INVEST_STREAK_LOTS`，非本輪新選）。

**不得**在本輪掃描窗長（10/20/40 日）、張數門檻、或改用外資／自營。
那些是新的自由度，會讓 H12 變成新的挖掘場——這正是舊策略累積到
n_trials ≳126 的機制。

### 覆蓋率斷點（M19）

法人資料 TWSE 自 2015 起、**TPEX 自 2018 起**。
**TPEX 2015~2017 的缺值不得讀成 `Confirm = 0`**，否則時間、市場別與訊號

| 欄位 | 內容 |

| **結論** | 🔴 **否決**（2026-08-14，且方向與假說相反，見下方結果） |

### 結論效力：歷史只能否證（2026-08-14 補登，原登記漏了這一節）

H13 的 BB B1 定義在 2015~2026 上**已經被 H01 測過、修正過、
看過報酬分布、看過排序結果**。因此即使 H13 問的是一個新問題，
同一段資料也**不能算 independent confirmation**：

| 資料 | 角色 |
|---|---|
| 2015~2026 | **falsification / development evidence only** |
| **2026-08-14 之後的 forward** | **唯一的 confirmatory evidence** |

與 H16 同一個定位。歷史資料仍然非常有價值，只是價值的方向是**否證**：

- 歷史上直接死 → 很好，不必浪費 forward attention
- 歷史上漂亮 → **survives falsification**，放進 forward shadow policy，**不是 validated**

### 這與 H01 是不同的問題

H01 問「B1 之後平均會不會漲」，**維持否決**。
H13 問的是：**等待 BB 確認的完整 policy，是否比不等待更好。**

### 受測對象是 policy，不是分組（2026-08-14 修正，M16）

原登記寫的是「Group A（基本面好＋已 B1）vs Group B（基本面好＋尚未 B1）」。
**那個寫法有前視**：「已 B1」是用未來事件在篩樣本，與先前那個把效果放大
約 8 倍的「只取後來有 B2 的 B1」本質相同。

改為比較兩個**當下可執行**的 policy：

| policy | 內容 |
|---|---|
| **F** | 營收條件成立 → T+1 買 |
| **F+BB** | 營收條件成立 → 最多等 **W = 20 個交易日**；期間出現 B1 就在其 T+1 買；**20 日內未出現 B1 則不買** |

`W = 20` 與「沒出現就不買」**事前固定**，兩者都是 policy 的一部分，
不得事後調整。實作一律經過 `research.policy:wait_for_trigger_entry`，
**未觸發的候選會保留在結果中**（`entered=False`），不會從樣本消失。

必須承認 F+BB 測的是「等待確認的完整 policy」（含選擇效果），
而不是「同一筆交易進場漂亮一點」。這是兩個不同的命題。

### 受測指標必須改變——這是本假說最重要的一點

**H01 只測了 return，對一個 timing 訊號那是錯的指標。**
一個把最大逆向波動由 -14% 壓到 -6% 而 return 不變的訊號，
在有停損、有資金成本的真實部位裡價值極大，但只看 return 會判它無效。

因此 H13 的主要指標是：

| 指標 | 定義 | 為何 |
|---|---|---|
| **median MAE** | 進場後 horizon 內盤中最低價相對進場價，取**組間中位數差** | timing 訊號的核心價值；報酬極度厚尾，中位數比平均穩健 |
| **Q25(MAE)** | 事前指定的下尾分位 | 較糟的四分之一交易 |
| **time-to-breakeven** | 首次達 **1.185%**（完整換手成本）所需交易日，右設限於 horizon | 門檻用外生已知的成本，不用 +3%/+5%/+10% 那三個自由度 |
| return | 次要，並列報告 | 不得單獨作為判準 |

**不得** q10／q20／q25／q33／q50 全看——那又是多重檢定。分位事前只鎖 Q25。

MAE 用**原始**報酬而非超額報酬：它的經濟意義是「離停損多近」，
而停損是看自己的價格觸發的。兩組經歷同一段市場，市場成分在組間差異中大致抵銷。
以盤中最低價計算，因為停損看盤中不看收盤。

time-to-breakeven 以**設限平均**（restricted mean）為主要統計量，
不用 Cox hazard ratio：時機訊號的效果很可能集中在前段（前 10 天差很多、
之後沒差），那會直接違反 proportional hazards 假設。

### 統計檢定：MAE 可以 bootstrap，但重抽單位要對

每筆交易的 MAE 是一個普通純量，研究的是 `Distribution(MAE_i)`，
**不是「全樣本裡最慘的那一筆」**——後者才是難處理的極值統計量。
因此 block／stationary bootstrap 仍然適用，
但**重抽單位必須是整個 episode 或整個日曆區塊**，
不得把同一筆交易的 Day1／Day2／Day3 拆開重抽。

### 曝險必須與 MAE 並列（M17）

**等越久、跳過越多股票，MAE 天生越好看；「永遠不買」的 MAE 是完美的 0%。**

因此下列全部必報，缺一不可（`research.policy:exposure_summary`）：

- `participation_rate`（20 日內出現 B1 的比例）
- `mean_wait_sessions` / `median_wait_sessions`
- 等待期間放棄的報酬（missed return）
- 最終 total return

### B2 在本輪是**狀態變數**，不是賣點

**不得**預設「第二次突破＝過熱＝賣出」。那是上一輪規格漂移的直接來源。
本輪只觀察三群的報酬分布：

1. B1 後一路趨勢（未回帶內）
2. B1 → 回帶內 → B2
3. B1 → 回帶內 → 未再突破

**先理解現象，再決定要不要拿它當出場條件。** 若資料顯示 B2 後報酬下降，
才有理由把它寫成 exit；若相反，則先前「B2 賣出」的方向是反的。

### 量能：先看形狀，不掃門檻

依 `RESEARCH_V2_PIPELINE.md` §5.1，先把 `Volume / MA20(Volume)` 當**連續變數**
看 Q1~Q5 對 MAE／time-to-profit／突破失敗率的關係，**再**決定要不要切、切在哪。
**不得**一開始就問「1.3 倍還是 1.4 倍比較好」。

## H16 — 基本面條件下的價格動能（Fundamental-conditioned Price Momentum）

> 登記：2026-08-14（**僅登記，尚未執行**）
> 這是 H11 之下與 H12 **平行**的 sibling，不是 H13 的變體，也**不是 MOM-1 的復活賽**。

### 為什麼這是一個新假說而不是 MOM-1 改版

MOM-1 已依 §9.5 否決。**無條件**的 `mom_6_1` 在 2008~2014 沒有排序能力
（rank IC = −0.0003）。H16 問的是完全不同的問題：

> 在**同樣有基本面改善**的公司裡，價格已經呈現中期強勢者，
> 之後是否比尚未呈現強勢者有更高的未來超額報酬？

這是 interaction，不是把否決過的因子再測一次。
`E[R | Mom] ≈ 0` 與 `E[R | Mom, Revenue+] > 0` 在邏輯上完全可以同時成立。

| 欄位 | 內容 |
|---|---|
| **機制** | 企業營運改善的資訊若正被市場**逐步**吸收，則「基本面已改善 ＋ 價格已開始反映」應比「基本面已改善但價格尚未反映」更可能延續。這是 fundamental 與 price information 的 **joint underreaction**。 |
| **機制先例** | Chen et al. (2014), *Does revenue momentum drive or ride earnings or price momentum?*, Journal of Banking & Finance。**僅作事前機制來源，不假定其結果可直接移植台股。** |
| **假說來源** | 使用者與外部審閱的機制推論（2026-08-14），加上上述文獻先例 |
| **Revenue+** | 沿 H11 凍結定義。**主要規格取 `yoy_pct > 0`**，理由是本層問的是「改善是否被逐步吸收」，較寬的母體也讓條件檢定有較多 breadth；`> 20%` 列為 robustness。此選擇基於機制與功效，**不是**看 H11 結果挑的。 |
| **Momentum+** | Revenue+ 合格母體內 `mom_6_1` 的**前 10%**，定義完全沿用 MOM-1（跳 20 日、回看 120 日、前 10% 進場），**不重新選形成窗** |
| **主要觀察窗** | **60 個交易日**（依 M12） |
| **型態** | 事件驅動（月頻） |
| **結論** | 🟡 **主要判準未通過，歷史 inconclusive**（2026-08-14，見下方執行結果） |

### 兩個估計量，但只有一個是主要判準

**Mechanism primary（統計判準）**

```
Δ_signal = E[R | Rev+, Mom+] − E[R | Rev+, Mom−]
```

回答：**在同樣有基本面訊號的公司中，價格動能是否額外區分未來報酬？**

**Economic secondary（只報告，不作判準）**

```
Δ_portfolio = E[R | Rev+, Mom+] − E[R | Rev+]
```

回答：原本要買整批 Revenue+，改成只買其中的 Mom+ 子集，可部署報酬提升多少？

**兩者不可互相替代**：`E[R | Rev+]` 的母體本身就含 Mom+ 那一群，
因此 `Δ_portfolio` 會被稀釋而低於 `Δ_signal`。
**事前指定 primary 為 `Δ_signal`**，不得「兩個之中有一個顯著就算通過」。

### 結論效力：歷史只能否證（**這條最重要**）

`mom_6_1` 的形成窗（跳 20、回看 120）是**看過 2015~2026 的 IC 表從四個候選挑出來的**
（SPEC §7.2 明載），而 2008~2014 已於 2026-08-14 耗盡。因此：

| 資料 | 角色 |
|---|---|
| 2015~2026 | **falsification / development evidence only** |
| **2026-08-14 之後的 forward** | **唯一的 confirmatory evidence** |

即使歷史資料跑出 `+3%、t=4`，**也只能宣稱「未被否證，且結果與機制相符」**，
**不得**宣稱「H16 已被獨立驗證」。幾個月後最容易犯的錯就是把它悄悄洗白成 OOS。

### 事前登記的規格與試驗次數

| | |
|---|---|
| **Primary specification** | 控制規模的條件橫斷面檢定（樣本限制在 Revenue+） |
| Robustness | 未控制規模；只做多的經濟換算；2×2 完整表 |
| **試驗次數** | **4**（保守記帳；四者非同等地位的候選模型） |

**不得**更改：6-1 形成窗、Top 10% 門檻、60 日主要窗；
**不得**新增 momentum 變體（12-1、persistence、residual、volatility-adjusted、intraday）。

### 必報的 breadth（否則選擇性會製造假象）

`P(Revenue+) ≈ 31%`，其中再取前 10% → 全市場只剩約 **3%**。
每月可能只有十幾到幾十檔。這不是問題，但**選擇性↑、breadth↓**，
因此下列全部必報，缺一不可：

- 每月 Revenue+ 檔數、Mom+ 檔數
- 相異股票數、可用月數
- 訊號集中度（單月最大佔比）
- 規模分布

**產業集中度無法正式控制**——2015~2026 沒有 PIT 產業
（`stock_industry_map.parquet` 無日期欄，見 H11~H15 §6.4）。
這是已知限制，必須在結果旁明說：**不能排除「+X% 其實來自某一族群」**。

### 經濟門檻在這一層**不是** 2.185%

H16 的 Layer 2 問的是「條件預測資訊存不存在」，不是「可否部署」。
Mom+ 是一個**選擇變數**：原本就要買 Revenue+，改成只買其中一部分，
**未必新增一整次完整換手**。因此不得用 2.185% 直接否決它。

真正的經濟判準留到 **H14**：
`Portfolio(Revenue + Mom) − Portfolio(Revenue only)`，**淨掉增量周轉成本**。

### 失敗條件

- 主要規格下 `Δ_signal` 在 60 日窗不顯著 → **H16 kill**
- 或未控制／控制規模兩個規格符號不一致（依 M9，且先檢查資料建構）

通過只能記為 **survives falsification**，進入 forward 累積，**不是 validated**。

### 與 H12 的對稱關係

| | 估計量 |
|---|---|
| **H12** | `E[R \| Rev+, Institution+] − E[R \| Rev+, Institution−]` |
| **H16** | `E[R \| Rev+, Momentum+] − E[R \| Rev+, Momentum−]` |

兩者是同一個模具、不同的 confirmation source，跑完可直接比較：

> **營收變好之後，是「法人開始買」比較有資訊，還是「價格已經開始強」比較有資訊？**

答案也可能是**兩個都沒有**——那同樣是有效結論。

### 一個必須記錄的實作更正

第一版把規模控制量在**進場日（landmark + 1）**。那是**post-treatment 變數**：

| Δ_signal 控制規模 | −0.086%（t=−0.21） | **+0.172%（t=+0.43）** |

### 而且 proxy 論證在這裡是再補一刀，不是替 Conf+ 說話

| | 何時可得 |

所以 proxy 的角度不但沒有救回 Conf+，反而讓「為什麼要用它」更沒有答案。

## H13 執行結果（2026-08-14）：🔴 **否決，且方向與假說相反**


**這句話的範圍必須寫準**：不是「Revenue 永遠無法變成策略」這種宇宙級結論，

No / Unknown / No」。停在這裡是**研究紀律**，不是認為再也沒有方法。

依 M22，這些屬 **Discovery 軌**：歷史資料可用但一律標 development，
跑出再漂亮也只是「值得放進 forward 的候選」。**列在這裡不佔試驗次數、不得直接執行**，
要跑必須先正式登記 H 編號。

### 候選一：營收成長的**持續性**（而非單期幅度）

| | |
|---|---|
| **文獻線索** | 台股 monthly revenue momentum 研究指出：**營收成長的強持續性會顯著放大動能利潤**，且在**套利成本高**的股票上更明顯 |
| **機制** | 單月 YoY 可能是雜訊或基期效應；連續數月的改善才代表營運趨勢，市場對趨勢的重新評價更慢 |
| **與我們已知的關係** | H11 用的是**單期** `yoy>0`／`>20%`。持續性是一個**沒測過的維度**，不是把 H11 換參數 |
| **資料** | 月營收 ✅ 2015~；套利成本可用成交金額／規模代理 ✅ |
| **可測性** | 🟢 **可以做** |
| **風險** | 「連續幾個月」是新自由度。若要做，必須事前只鎖**一個**定義（例如連續 3 個月 YoY>0），不得掃描 |

### 候選二：營收公告前後的 MAX（樂透偏好）效應

| | |
|---|---|
| **文獻線索** | 台股研究發現高 MAX（過去一個月最大單日漲幅）股票在**營收公告前 5 日**有正異常報酬，**公告後 5 日反轉** |
| **機制** | 散戶的樂透偏好在事件前推升價格，事件後修正——這是**台股散戶結構**的直接後果 |
| **資料** | MAX 由日報酬可算 ✅；**但需要逐檔實際公告日** ❌ |
| **可測性** | 🔴 **data-blocked** |
| **為什麼卡住** | 我們只有「公布月月末」的保守近似（M14 已登記為已知限制）。±5 日的事件窗**需要真正的公告日**，用月末近似會把整個效應洗掉 |
| **解鎖條件** | 補逐檔月營收實際公布日。這也會同時解掉 H11 的偽陰性風險——**是目前投資報酬率最高的一項資料工作** |

### 候選三：法人羈群 × 市場狀態

| | |
|---|---|
| **文獻線索** | 2025 年台股研究：法人羈群在**市場下跌期**正向預測未來超額報酬，在**多頭期**反向 |
| **機制** | 下跌時法人集中買進代表資訊；多頭時羈群更像追價 |
| **資料** | 法人 ✅（TWSE 2015~／TPEX 2018~）；市場狀態可用 0050 MA200 ✅ |
| **可測性** | 🟢 可以做 |
| **⚠️ 最大的風險：這很像 H12 的復活賽** | H12 測的是**無條件**的法人確認，結論是機制否決。加一個 conditioning variable 直到它變顯著，正是本專案要避免的模式 |
| **若要做，必須滿足** | ①機制敘述來自**文獻先驗**，不得寫成「因為 H12 失敗所以加條件」②市場狀態定義沿用既有凍結的 0050 MA200，不得新選 ③事前登記，且**明載它與 H12 的關係**④結論效力仍是 falsification only |

### 候選四：當沖稅減半（2017-04）作為自然實驗

| | |
|---|---|
| **文獻線索** | 2017-04 當沖證交稅減半至 0.15%；研究發現它推升成交量、擴大買賣價差與波動，且不同投資人類型反應不同 |
| **機制** | 這是一次**外生的交易成本變動**，可用來檢驗「成本結構改變如何影響價格行為」 |
| **對本專案的價值** | 我們的成本模型是**全期固定 1.185%**（M8 已列為已知限制）。2017-04 是一個真實的斷點，**現行模型跨越它卻沒有調整** |
| **資料** | 價量 ✅；**但缺當沖成交量與比重** ❌ |
| **可測性** | 🟡 **部分**：可測「制度前後的價格行為差異」，不能測「當沖活動本身的影響」 |
| **建議** | 先不當成新策略假說，而是**把它當成成本模型的檢查**：2017-04 前後的有效成本是否該分段 |

### 候選五：處置新制（2026-08-10）作為自然實驗

| | |
|---|---|
| **事實** | 關押由 10 個交易日縮為 5 日、撮合由 5／20 分縮為 2 分，近 30 年最大調整 |
| **對本專案的價值** | REV-1A 已因此暫緩。這是一個**正在發生**的結構斷點 |
| **資料** | 處置事件 ✅（2005~2014 共 604 筆；forward 剛開始累積） |
| **可測性** | 🔴 **現在不能做**——新制才上路數日，post-change 觀測近乎為零 |
| **建議** | 列入 forward 觀察，**至少累積 12 個月**再談。現在做任何結論都是雜訊 |

### 我對這五個的排序建議

| 優先 | 項目 | 理由 |
|---|---|---|
| **1** | **補逐檔營收公告日**（不是假說，是資料工作） | 同時解鎖候選二、修掉 H11 的偽陰性風險、讓 M14 從「已知限制」變成「已解決」。**投資報酬率最高** |
| 2 | 候選一（營收持續性） | 資料齊、與 H11 是不同維度、自由度可控 |
| 3 | 候選四（當沖稅斷點） | 不是新策略，是**現有成本模型的體檢**，價值在於讓後續所有結論更可信 |
| 4 | 候選三（法人×市場狀態） | 有文獻先驗，但復活賽風險最高，要寫得非常小心 |
| 5 | 候選五（處置新制） | 時候未到 |

**注意第 1 項不是假說。** 目前這條研究線最大的瓶頸不是「想不出假說」，
而是**營收公告日這個資料缺口**——它同時卡住候選二、限制 H11 的精度、
並且是 M14 唯一沒解掉的部分。

# 假說登記簿（Research V2）

> 規範：`docs/RESEARCH_V2_PIPELINE.md` §4
> 驗收流程：`docs/STRATEGY_VALIDATION_PROTOCOL.md`

**規則**

1. **跑第一行程式之前**先在這裡加一列。事後補登一律標 `(補登)`。
2. 「假說來源」欄決定哪段資料還能用——若來自回測挖掘，那段資料就不能再當驗收集合。
3. 「所需資料」必須註明**該資料在目標期間是否存在**。這一欄是 REV-1B 與
   布林 Chip 因子的死因，不可略過。
4. 「型態」決定獨立樣本數要用情境聚合還是 block bootstrap（§3）。
5. 結論欄只能填 **採用 / 否決 / 待驗**。

## H01 — 布林二次突破（Volatility expansion + re-breakout）

| 欄位 | 內容 |
|---|---|
| **機制** | 第一次帶量突破上沿代表新資訊進場、趨勢啟動。回落至通道內是獲利了結與換手。第二次突破時，追價者已進場完畢，最後一批買方是看到型態才進來的散戶——他們沒有資訊優勢、部位小、停損近。對手方是刻意在此製造價格的大戶：**若大戶同步增加持股＝換手後續攻；若大戶減碼＝拉高出貨**。因此第二次突破本身不帶方向，方向由「誰在接」決定。 |
| **假說來源** | 使用者看盤觀察（**非**回測挖掘）→ 依 PIPELINE §6，全部歷史資料可用 |
| **事件定義** | BB(20, 2σ)；帶寬 >過去 60 期中位數；成交量 ≥20 期均量；狀態機：突破上沿→收盤回到帶內→再次突破上沿。週 K 定 regime、日 K 抓進出場。 |
| **所需資料** | 價量 ✅ 2015~ 完整／法人買賣超 ✅ TWSE 2015~、TPEX 2018~／**TDCC 大戶持股 ❌ 免費源僅當週，無歷史** |
| **型態** | **連續橫斷面**（實測 2,714/2,812 個交易日都有訊號）→ 用 block bootstrap，**不可**用情境聚合 |
| **預計試驗次數** | 待定，下限 12（5 單因子分位 + 4 ablation + 3 baseline） |
| **失敗條件** | Phase 2 的 CAR 在 5/10/20/40/60 日全部不顯著；或 Phase 3 的 Random baseline ≈ Full ranking |
| **結論** | **待驗**（尚未凍結，尚未執行任何回測） |

**已知地雷（2026-08-13 實測）**

1. **Chip 因子必須改用法人買賣超。** TDCC 免費源只給當週，10 年歷史要付費；
   `tdcc_fetcher.py` 檔頭 2026-07-26 已判定「現在無法做嚴謹回測因子研究」。
   法人買賣超反而更適合：**日頻**、且分外資／投信／自營，直接回答「誰在接」。
2. **訊號不具選擇性。** 每日觸發中位數 20 檔、p90 44 檔、最多 164 檔。
   決定報酬的是排序規則，不是布林。必做 §2 Phase 3 的三組 baseline。
3. **週 K 循環太長不可直接交易。** 循環長度中位數：日 K 25 個交易日、
   **週 K 19 週**（p75 40 週）。週 K 只能定 regime。
4. **Pullback duration 需要事前固定的上限。** 第一次突破後 60 期才二次突破，
   是否仍算同一個 setup？未定義會讓事件母體失控。

## H04~H06 — 現行策略殘存因子的重新驗證

現行波段策略已封存不再調參（`RESEARCH_V2_PIPELINE.md` §1），但其中三個因子
在 P1 十年因子研究中證據相對較強，值得用 Phase 2 的正確方法重新檢驗。

**這三個的處境與 H01 完全不同，必須先講清楚。**

### 為何不能像 H01 那樣自由使用 2015~2026

| | H01 布林 | H04~H06 |
|---|---|---|
| 假說來源 | 看盤觀察 | **2026-07-19 P1 因子研究（2015~2026 資料）** |
| 依 PIPELINE §3.1 決策樹 | 走右邊：全部資料可用 | **走左邊：該段資料已污染** |

而且更麻煩：**乾淨期間根本沒有這些資料**。release `tw_stock_data_2005_2014_r2`
的九個元件裡沒有 `monthly_revenue`、也沒有 `institutional`；本機這兩份都從
2015-01 才開始。

**所以 H04~H06 沒有任何可用的 backward 驗收期間。** 這與 REV-1B 死於融資餘額
是同一種處境。

### 但仍值得做：污染資料可以否證，不能確認

這是 §9.2 F1 重新定位的同一個邏輯，套用到因子層：

| 結果 | 可以宣稱 | 不可以宣稱 |
|---|---|---|
| 效果**消失** | 該因子被否證，正式除役 | — |
| 效果**存活** | 「在正確方法下沒有被否證」 | ❌「有效」 |

P1 的舊研究有 `SPEC_DATA_FOUNDATION_AND_MOMENTUM.md` §1.3 記載的五項方法缺陷，
其中兩項會**系統性高估**顯著性：

1. 因子在收盤後才完整可知，舊報告卻**從同日收盤**計 forward return
   → 必須改為 T+1 可成交價
2. 20/60/120 日 forward return 大量重疊，把每日 IC 當獨立樣本算 t-stat
   → 必須改用 Newey-West、非重疊抽樣或 block bootstrap

**若某個因子在修正這兩項後就消失，那是真實的負面結果，且立刻省下 12 個月的
forward paper。** 這就是做它的理由。

| H04b `rev_yoy>20%` | 30,294 | +0.017% | +0.522% | +0.794% | +1.322% | +1.883% |

**30 個窗格中顯著者：1 個**——H09 的 5 日窗，且方向為**負**（p=0.00）。

### H07／H09 的判讀

- **H07 外資買超**：37 萬個事件、1,892 檔股票，五個窗全部為**負**，
  但都不顯著。外資買超首日在扣掉 beta 後沒有正向資訊。
- **H09 多頭排列**：唯一顯著的窗格，但**方向與策略假設相反**——
  多頭排列成立首日後 5 日超額報酬為 **-0.335%**。這與 P1 記載
  「stack_days 要 60 日以上才顯著」的說法方向不合，也與 `w_trend_stack=0.8`
  的正權重相反。
- **H08 `etf_accum` 無法測試**：它需要營運 DB 的 `etf_changes` 表，
  不在 parquet 快照內。依 PIPELINE §1 步驟 2，識別資料不存在即停，
  **不以代理指標硬湊**。這是 data-blocked，不是被否證。

### 為什麼舊研究看起來有效：原因已分離出來

以 H05 的 60 日窗做對照實驗：

| 方法 | CAR60 | naive t |
|---|---:|---:|
| 事件日收盤進場 ＋ **原始報酬** | **+3.951%** | +29.4 |
| 事件日收盤進場 ＋ 超額報酬 | +0.565% | +4.0 |
| T+1 開盤進場 ＋ 原始報酬 | +3.841% | +28.5 |
| T+1 開盤進場 ＋ **超額報酬** | +0.502% | +3.5 |

**最大的殺手是「原始 → 超額」：+3.95% 裡有 86% 只是市場 beta。**
T+1 對齊的影響只有約 0.06pp。

第二個殺手是 block bootstrap：同一組資料 naive t=+3.5（看似顯著），
但以 20 個交易日分塊重抽後 p=0.74。34,832 個事件只落在 2,769 個相異日、
且 60 日窗大量重疊，有效樣本數遠低於事件數。

**這個對照同時證明引擎沒有偽陰性**：用舊方法能重現巨大的正效果，
換成正確方法才消失。

### 判決

五個可測因子在正確方法下**全部否決**，其中 `stack_days` 還出現反向顯著。

| 因子 | 權重 | 判決 |
|---|---:|---|
| `rev_yoy` | 3.0 | 否決 |
| `invest_streak` | 2.5 | 否決 |
| `invest_new_entry` | 2.5 | 否決 |
| `rev_accel`（H04b） | 1.0 | 否決 |
| `foreign_buy` | 1.0 | 否決 |
| `trend_stack` | 0.8 | **否決，且 5 日窗反向顯著** |
| `etf_accum` | 1.0 | **無法測試**（資料不在快照） |
| **已否決權重合計** | **10.8 / 11.8** | **91.5%** |

現行策略非零權重的 **91.5%** 建立在經不起正確方法檢驗的因子上，
剩下 1.0 的 `etf_accum` 因資料缺席而無法判定。

依 `RESEARCH_V2_PIPELINE.md` §6，否決即記入登記簿並停止，不得加濾網重測。

### 本次結果的限制（誠實記錄）

1. **月營收公布日為保守估計**。官方規定次月 10 日前公布，逐檔實際公布日
   不在快照內，本次取「次月 10 日後第一個交易日」。這保證不使用未公布資訊，
   但若多數公司提早公布，會系統性錯過初期反應——**這是偽陰性風險**。
   若要推翻本判決，正確做法是補逐檔實際公布日重測，而不是放寬統計門檻。
2. 投信連買採「連續 3 日買超」的簡化定義，未含 `agent/strategy.py` 的量體門檻。
3. 本測試只能否證、不能確認（見上）。**否決是有效結論；若當初存活，才不能宣稱有效。**

### H04~H06 共同的執行約束

- 三個假說合計 **4 次試驗**（H04a、H04b、H05、H06），須計入累計 n_trials

- **報告必須標明「此為否證測試，效果存活不構成正面證據」**

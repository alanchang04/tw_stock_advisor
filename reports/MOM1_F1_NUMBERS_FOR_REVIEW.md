## 0. 先講三件會影響你怎麼讀所有數字的事

## 1. Signal 本身（L1／L2）

> **問題**：過去 momentum percentile 越高，未來報酬有沒有大致往上？

### 怎麼算的

**完全不經過組合與執行**——這一層要回答「現象存不存在」，
所以不能讓 10 檔上限、產業上限、成本混進來。

1. 取 2008~2014 的每個月末決策日（共 84 個，可配對成 83 對）
2. 每個決策日跑與策略**完全相同**的 `eligible_universe`（§7.1 七條件）
   → 每月中位數 **339 檔**合格
3. 依 `mom_6_1` 把當月合格股票切成 10 等分（`qcut` on rank，避免同分擠壓）
4. 前瞻報酬 = 還原收盤價從本次決策日到**下次決策日**（約 1 個月），
   不扣成本、不做 T+1
5. 每個分位每月取等權平均 → 再對 83 個月取平均
6. rank IC = 每月 Spearman(`mom_6_1`, 前瞻報酬)，再對月序列做 Newey-West（lag 6）

### 結果

| 分位 | 月均報酬 |
|---|---:|
| D1（最弱） | +0.749% |
| D2 | +0.753% |
| D3 | +0.592% |
| D4 | +0.776% |
| D5 | +0.647% |
| D6 | +0.836% |
| D7 | +0.886% |
| D8 | +0.616% |
| **D9** | **+1.079%** |
| **D10（最強）** | **+1.159%** |

| | |
|---|---|
| D10 − D1 | **+0.409%／月**（約 +5.0%／年） |
| D10 − D1 的 t 值 | **0.612** |
| mean rank IC | **−0.0003** |
| rank IC 的 t 值 | **−0.017** |
| IC 為正的月份比例 | **53.0%** |
| 月數 | 83 |

### 判讀

**不是單調的。** D1~D8 在 +0.59% ~ +0.89% 之間亂跳，看不出趨勢；
只有 D9／D10 明顯抬高。

**rank IC 幾乎正好是 0（−0.0003，t = −0.017）。** 作為一個**排序**訊號，
`mom_6_1` 在這段期間沒有可測到的單調排序能力。

但**這不等於「台股沒有中期動能」**，兩個理由：

- D10 相對全體平均（10 個分位平均 ≈ +0.809%／月）高出 **約 +0.35%／月 ≈ +4.3%／年**，
  這在經濟上不小，只是統計上分不出來（t = 0.61）
- IC 的標準誤 = 0.0165 → 95% CI = **[−0.0326, +0.0320]**。
  **這裡先前寫錯了**：原文說「文獻級 IC 0.02~0.05 沒有被排除」，
  但 0.04 與 0.05 **其實已經在區間之外**。正確的說法是

  > **弱的正 IC（約 0.02~0.03）仍與資料相容；強的排序能力（IC ≈ 0.04~0.05）
  > 已經不太相容。**

  這讓結論更清楚而不是更模糊：不是「什麼程度的動能都可能存在」，
  而是**強排序能力已可排除，只剩弱排序能力還開著**

**所以 L1／L2 的正確標籤是「不確定，偏向無」，不是「已否證」。**
83 個月、月波動這麼大的樣本，撐不起更強的宣稱。

## 2. Gross portfolio（不扣成本）

> **問題**：組合建構有沒有把訊號保留下來？

### 怎麼算的

把 `FEE_RATE`、`TAX_RATE` 全部設為 0，`buy_fill`／`sell_fill` 換成恆等函式
（＝無滑價），其餘規則**完全不動**，重跑同一個引擎。
這是 exploratory 歸因，**不是**把成本拿掉讓策略好看——判決一律用 net。

### 結果

| | 總報酬 | CAGR | Sharpe | MDD |
|---|---:|---:|---:|---:|
| **MOM-1A gross** | +119.42% | **+12.11%** | 0.401 | −69.31% |
| **MOM-1B gross** | +130.12% | **+12.89%** | 0.639 | −30.18% |
| 等權 universe（無成本） | +52.09% | +6.29% | — | — |
| 0050 含息 | +40.85% | +5.11% | — | — |

### 判讀

**gross 的 MOM-1A 比等權 universe 高 5.8pp／年**（12.11% vs 6.29%）。
所以組合建構**確實**保留住了東西——這與 §1 的 IC ≈ 0 並不矛盾：

> 策略只買最強的約 10 檔，全部落在 D10。
> D10 比全體平均高約 +0.35%／月，年化約 +4.3%，
> 加上 10/20 buffer 讓它更集中在最強的一端——量級對得起來。

**換句話說：訊號沒有單調排序能力，但它的最右端（D10）確實比平均好；
MOM-1 只買最右端，所以 gross 有東西。**

**但那個「D10 比較好」本身 t = 0.61，不顯著。**
gross 的 +5.8pp/年，很可能只是一個沒有統計支撐的樣本內現象。

## 3. Net portfolio（扣真實成本）

### 怎麼算的

成本沿用 `agent/strategy.py` 的正式常數，**不是本輪自訂**：

| 項目 | 值 |
|---|---|
| 手續費 | `0.001425 × 0.58 = 0.08265%`，**買賣各收一次** |
| 證交稅 | `0.30%`，**僅賣出** |
| 滑價 | `0.30%` 單邊（買入成交價 ×1.003、賣出 ×0.997） |

成交價＝T+1 開盤 ×(1±滑價)；股數 = `floor(目標名目 / 成交價)`，
另受「近 20 日均量 1%」上限。

### 結果

| | gross CAGR | **net CAGR** | 成本拖累 | 明確成本 | 年周轉 |
|---|---:|---:|---:|---:|---:|
| MOM-1A | +12.11% | **+7.84%** | **−4.28pp／年** | 40,891 | 4.38x |
| MOM-1B | +12.89% | **+8.66%** | **−4.23pp／年** | 55,087 | 5.83x |

「明確成本」只含手續費＋證交稅；**滑價不在其中**，它已含在成交價裡，
所以「成本拖累 4.2pp」大於「明確成本 ÷ 年數」。

### 判讀

**成本吃掉了 gross edge 的三分之一到一半。** 10/20 buffer 確實壓低了周轉
（修正引擎後每個決策月只成交 2.2 筆），但年周轉仍有 4.4~5.8 倍。

## 4. Benchmark-relative

### 怎麼算的

- **0050 含息**：用 release 的還原收盤價（含官方 D3 調整因子），
  期初收一次買進手續費。`47.4611 → 66.8500`，比值 **1.408521**。
- **等權 universe**：SPEC §8.1 基準 2。每月末等權持有當期合格 universe
  到下個決策日，逐月連乘，不計成本。
- 年化超額 = 策略 CAGR − 基準 CAGR（幾何差，不是算術平均差）
- beta／TE／IR 用**日報酬**：beta = cov(策略, 基準)/var(基準)，

## 5. Return distribution

### 怎麼算的

- 交易＝一個部位從 0 股買進到回到 0 股，`net_pnl = 賣出淨額 − 買入成本（含費）+ 持有期間公司行動配息`
- 「移除最佳 5 筆」＝把 `net_pnl` 由大到小排序後，去掉前 5 筆再加總
- 「拿掉最佳年份」＝把該年的**月報酬**整段拿掉，其餘年度連乘
- 「單一年份佔毛利」＝只計**獲利**交易的當年合計 ÷ 全期獲利交易合計

### 結果

| | MOM-1A | MOM-1B |
|---|---:|---:|
| 交易數 | 222 | 211 |
| 勝率 | 50.5% | 46.4% |
| 交易淨損益 | +164,128 | +190,593 |
| **移除最佳 5 筆後** | **−66,791** | **−39,576** |
| 前 1／5／10 筆佔毛利 | 8.6% / 25.6% / 39.8% | 5.6% / 24.5% / 40.2% |
| 交易過的相異股票 | 185 檔 | 163 檔 |
| 前 3 檔佔毛利 | 19.7% | 20.0% |
| 最大年度佔毛利 | 25.4% | 25.4% |

年度報酬：

| | 2008 | 2009 | 2010 | 2011 | 2012 | 2013 | 2014 |
|---|---:|---:|---:|---:|---:|---:|---:|
| MOM-1A | **−53.0%** | **+134.7%** | +27.7% | −27.8% | +23.2% | +43.3% | −6.4% |
| MOM-1B | **+0.2%** | **+87.6%** | +8.7% | −8.0% | −13.0% | +31.1% | −17.5% |
| 0050 | — | — | — | — | — | — | — |

**拿掉最佳年份（兩者都是 2009）後的全期連乘報酬：**

| | 含 2009 | **不含 2009** |
|---|---:|---:|
| MOM-1A | +67.97% | **−28.44%** |
| MOM-1B | +76.99% | **−5.67%** |

### 判讀

三個集中度指標指向不同結論，**這件事本身值得注意**：

- **個股**不集中（185／163 檔，前 3 檔僅約 20%）→ 不是靠某 3 檔
- **單一年份佔毛利** 25.4%，**通過** §9.2 的 40% 門檻
- 但**拿掉 2009 就由正轉負**，而且**移除最佳 5 筆交易就變負**

**§9.2 的「單一年份佔毛利 ≤ 40%」寫得比它想擋的東西鬆。**
它只看獲利交易的毛利分佈，看不到「拿掉那一年整體會不會死」。
兩個都通過 40% 門檻的變體，拿掉 2009 之後一個 −28%、一個 −5.7%。

**這是一個規格設計的教訓，但不能拿來翻案**——門檻在開封前凍結，
看到結果後改判準正是 §9.2 禁止的事。它只能寫進「下一次怎麼訂門檻」。

## 6. MOM-1A vs MOM-1B（MA200 濾網做了什麼）

MOM-1B ＝ MOM-1A ＋「0050 含息收盤 < 其 200 日均線 → 下一交易日開盤降至全現金；
站回均線後於下一個月頻決策日恢復選股」。

| | MOM-1A | MOM-1B | 差 |
|---|---:|---:|---:|
| CAGR | +7.84% | +8.66% | **+0.82pp** |
| 年化波動 | 30.12% | 20.15% | **−9.97pp** |
| **最大回撤** | **−70.11%** | **−34.27%** | **+35.84pp** |
| Sharpe | 0.260 | 0.430 | +0.170 |
| Calmar | 0.112 | 0.253 | +0.141 |
| beta | 0.78 | 0.24 | −0.54 |
| **2008 年** | **−53.0%** | **+0.2%** | **+53.2pp** |
| 2009 年 | +134.7% | +87.6% | **−47.1pp** |
| 月勝率 | 55.4% | 34.9% | −20.5pp |
| 平均持股 | 9.75 | 5.85 | |
| 平均現金比 | 3.0% | 41.7% | |
| 全現金交易日 | 22 / 1,732 | **703 / 1,732** | |

### 判讀

**濾網四件事全做到了，代價也很明確：**

- 提高 return：**是**，但只有 +0.82pp／年
- 降低 MDD：**是，而且幅度巨大**（−70.11% → −34.27%）
- 降低波動：**是**（30.1% → 20.2%）
- 錯過反彈：**是**。2009 少賺 47.1pp，月勝率掉 20.5pp，四成時間空手

**它的價值幾乎全部集中在 2008 那一年**（+53.2pp）。
2010~2014 五年裡有三年 MOM-1B 輸給 MOM-1A（2010 +8.7 vs +27.7、
2012 −13.0 vs +23.2、2014 −17.5 vs −6.4）。

### 但「價值全在 2008」不足以判它無效——這裡先前講得太快

崩盤保險的 payoff 結構本來就是「平常小幅拖累、崩盤時大幅幫助」。
台股級別的崩盤 7~10 年才一次，**要求它每年都創造價值本身就不合理**。

真正的問題不是「價值集中在 2008」，而是：

> **樣本裡只有一次危機觀測。** 因此無法估計
> 「下一次崩盤時 MA200 仍能避開」的機率。

所以正確標籤是 🟡 **符合 crash-control 機制，但 N=1 無法驗證**，不是 🔴。
這與 MOM-1 整體 FAILED 不衝突——濾網有沒有效，和策略過不過門檻是兩件事。

**而 §9 的歸因診斷帶來一個更麻煩的發現：把同一個 MA200 濾網套在
等權 universe 上，總報酬由 +52.09% 掉到 +2.10%。**

|---|---:|---:|
| 每決策月成交筆數 | **38** | **2.2** |

`parameter tuning on 2008-2014 returns`。判決方向兩次相同（都 FAILED、

**單元測試沒抓到的原因**：fixture 價格全程持平，目標股數剛好不會漂移。
**扁平價格的 fixture 無法偵測周轉率缺陷。** 已補三條使用波動價格的迴歸測試
（`TestRebalanceFrequency`），並以突變測試確認它們會轉紅。

## 8. 三層判決

**L2 必須拆成兩個問題**，否則會把兩件不同的事混為一談：

| 層 | 真正的問題 | 判決 |
|---|---|---|
| **L1** | 2008~2014 台股是否存在中期報酬延續？ | 🟡 **無法確認** |
| **L2a** | `mom_6_1` 能否作為**全市場連續排序**因子？ | 🔴 **沒有證據**。IC = −0.0003；且強排序能力（IC≈0.05）已可排除 |
| **L2b** | `mom_6_1` 的**極右尾**是否有 threshold effect？ | 🟡 **有點估計、且通過所有可測的穩健性檢查，但統計上仍不確定** |
| **L3** | MOM-1 這套交易規則值不值得部署？ | 🔴 **否決** |

這個區分很重要，因為分位長成 `D1~D8 ≈ random、D9/D10 抬高`。
那**不是** `動能↑ ⇒ 報酬↑` 的單調關係，但仍可能是
`動能 > P90 ⇒ 報酬上升` 的**門檻效應**——兩者完全不是一回事。

而 MOM-1 幾乎只買 D10，所以真正對應它的估計量不是 rank IC，而是
`E[R | D10] − E[R | universe]`。**§9 的診斷正是在測這個。**

### 一句話總結

> 在未見過的 2008~2014 資料上，6-1 動能的最右尾出現**經濟上不小的正點估計**
> （+0.39~0.45%／月，且**通過規模控制與 T+1 執行檢查**），
> 但**缺乏統計與跨期穩健性**；全橫斷面排序能力近乎為零。
> MOM-1 組合的歷史超額報酬在扣除高周轉成本後大幅縮小，
> 且高度依賴 2009 與少數贏家，因此**依預先凍結的規則拒絕 MOM-1**。

**這不是「台股沒有動能」，也不是「MOM 賺 8.66% 所以有效」。**

**依 §9.5，MOM-1 否決；2008~2014 已耗盡，不得在同一 holdout 調參。**
若要研究 12-1／殘差動能／產業動能／波動調整動能，須另立 MOM-2 規格
並承認該段已被看過。

累計 n_trials：≳126 → **≳128**（MOM-1A、MOM-1B）。

## 9. 事後解剖四項（**EXPLORATORY — CANNOT REVERSE F1**）

外部審閱指出報告有四個推論漏洞，全部補測。
指令 `python scripts/diagnose_mom1_postmortem.py`；結果 `reports/mom1_postmortem.json`。
依 §8.3 全部標示 exploratory，**不得用於翻案**。

### A. 配對 bootstrap：檢定錯的估計量已修正

原報告 bootstrap 的是「策略 CAGR 的 CI 含不含 0」（MOM-1B [−3.79%, +35.59%]）。
**那不是真正的虛無假設**——策略與市場高度同漲跌，單獨看策略報酬的 CI 必然很寬。
改成配對月報酬差 `R_MOM,t − R_bench,t` 再 block bootstrap（6 個月 block）：

| | 年化超額 | 月差 CI95 | p(≤0) |
|---|---:|---|---:|
| MOM-1A vs 0050 | +5.46% | [−0.90%, +1.87%] | 0.260 |
| MOM-1A vs 等權 universe | +4.08% | [−0.50%, +1.47%] | 0.200 |
| MOM-1B vs 0050 | +3.03% | [−1.07%, +2.04%] | 0.333 |
| MOM-1B vs 等權 universe | +1.68% | [−1.27%, +2.17%] | 0.340 |
| **MOM-1B vs（等權 + MA200）** | **+9.82%** | [−0.10%, +1.73%] | **0.038** |

**配對之後精度確實高很多**（月差 CI 約 ±1.5%，而原本的年化 CI 有 ±35%）。
外部這個方法學意見成立。

但**結論不變**：對真正有意義的基準（0050、等權 universe），
p 值落在 0.20~0.34，**都不顯著**。

最後一列 p = 0.038 是本輪 6 個比較中唯一低於 0.05 的，
依 M2 的多重檢定記帳（6 格、α=0.05 期望誤報 0.3 格）它**還沒有到可以單獨引用的程度**，
而且它是事後才想到要比的基準。

### B. 等權 + MA200：外部的猜測被資料推翻了

外部懷疑「MOM-1B 的優勢可能只是 MA200 擇時，不是動能」。**實測相反：**

| 基準（2008~2014，不計成本） | 總報酬 |
|---|---:|
| 等權 universe | **+52.09%** |
| **等權 + MA200** | **+2.10%** |
| 0050 含息 | +40.85% |

**把同一個 MA200 濾網套在等權 universe 上，總報酬從 +52.09% 掉到 +2.10%。**
單獨的 MA200 擇時在這段期間是**大幅有害**的（避開了 2008，但也錯過了大部分回升）。

所以 MOM-1B 的表現**不是**擇時帶來的；控制擇時之後，
動能選股的貢獻反而是全部比較裡最大的一個（+9.82%／年）。

**這對 MOM-1 的判決沒有影響**（它仍未過門檻），
但它改變了「下一次要不要再碰動能」的判斷依據。

### C. 規模控制：D10 的優勢**不是**小型股曝險

逐月 `R[i,t+1] = a + b·I(mom > P90) + c·log(市值) + e`，市值用 PIT
`issued_shares × close`，再對 b 做 Newey-West（lag 6）：

| 規格 | 月均 | t |
|---|---:|---:|
| 未控制 | +0.3896% | 0.859 |
| **控制 log 市值** | **+0.3945%** | **0.957** |

**幾乎沒動。** 外部懷疑的規模混淆**沒有出現**——
這與月營收研究的情況不同（那裡規模控制確實改變了數字）。

仍然不顯著（t ≈ 0.96）。

### D. T+1 開盤執行：隔夜跳空**沒有**吃掉效果

原診斷用「月末收盤 → 下月末收盤」。改成策略真正的執行時點
「T+1 開盤 → 下期 T+1 開盤」：

| | 收盤→收盤 | **T+1 開盤→T+1 開盤** |
|---|---:|---:|
| rank IC | −0.0003（t=−0.017） | **+0.0070（t=0.446）** |
| Top decile − universe | +0.35%／月（t=0.61） | **+0.4474%／月（t=1.137）** |

**可執行版本反而略好**，不是變差。外部擔心的「預測得到但賺不到」在這裡沒有發生。

### 四項合起來說了什麼

最右尾效應是 **+0.39% ~ +0.45%／月**，而且

- ✅ **通過規模控制**（C）
- ✅ **通過執行時點檢查**（D）
- ✅ **不是擇時帶來的**（B）
- ❌ **t 值只在 0.86 ~ 1.14 之間，仍然不顯著**（A、C、D 一致）

**能測的混淆全部排除了，剩下的就只是樣本不夠。**
83 個月撐不起這個量級的推論——這正是「點估計漂亮但不能當 edge」的教科書案例。

**MOM-1 的否決不變。** 但「動能這條線是否值得未來再碰」的答案，
從「大概不值得」變成「**點估計穩健、只是無法確認；若要再碰，
必須用全新的資料，而且來源不能是『看 MOM-1 哪裡不好』**」。

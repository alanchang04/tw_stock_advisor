## 0. 本文件只涵蓋 Phase 2

Phase 2 只回答一件事：

> **這個事件之後，相對大盤會不會漲？**

因此本文件**刻意不含**：停損、trailing、部位大小、排序權重、產業上限、
市場濾網、換手成本。那些屬 Phase 3~5，現在寫進來就會重蹈「進出場混在一起
優化」的覆轍。

Phase 2 沒過就停，不准「加個濾網再看看」。

## 1. 機制假說

第一次帶量突破布林上沿代表**新資訊進場、趨勢啟動**。價格回落至通道內是
獲利了結與換手。到了第二次突破時，追價者已大致進場完畢，
**最後一批買方是看到型態才進來的散戶**——他們沒有資訊優勢、部位小、停損近。

對手方是刻意在此製造價格的大戶。因此第二次突破**本身不帶方向**，
方向由「誰在接」決定：

- 大戶／法人同步增加持股 → 換手完成，後續有承接
- 大戶／法人減碼而散戶追價 → 拉高出貨

這個假說可否證：若第二次突破無論法人買賣超如何都給出相同的 forward return，
機制即不成立（見 H03）。

**假說來源：使用者看盤觀察，非回測挖掘。** 依 PIPELINE §6，
2015~2026 全部歷史資料對本假說均可用。

## 2. Universe

事件日須同時滿足：

1. TWSE／TPEX 普通股，依 PIT master 判定（**不得以代號猜測**排除 ETF／TDR／權證）
2. 事件日為有效上市（`listing_date <= t < delisting_date`）
3. 至少 252 個有效交易日歷史
4. 事件日收盤價 >= 新台幣 10 元
5. 過去 20 日平均成交金額位於當日同市場普通股前 50%
6. 非處置／變更交易方法（沿用 MOM-1 的 `restricted` 合併矩陣）
7. 訊號所需欄位無缺值，缺值不得補 0

> ⚠️ **TPEX 法人資料 2018 前不存在**，不得補 0。依 §8.3：H01 Phase 2
> 只用價量，**納入 TPEX**；H02／H03 需要法人，納入 TPEX 時須限定 2018 起。

## 3. 事件定義（狀態機）

指標一律 **BB(20, 2σ)**，不得調整週期或倍數。

```
帶寬        = (上沿 − 下沿) / 中軌
帶寬擴張    = 帶寬 > 過去 60 期帶寬中位數
量能確認    = 成交量 >= 過去 20 期均量
```

狀態機（做多側）：

| 狀態 | 條件 | 動作 |
|---|---|---|
| `flat` | 收盤 > 上沿 **且** 帶寬擴張 **且** 量能確認 | 記為 **B1**，轉 `engaged` |
| `engaged` | 收盤回到通道內（收盤 <= 上沿） | 轉 `retreated` |
| `retreated` | 收盤 > 上沿 | 記為 **B2＝事件日**，轉 `flat` |
| `retreated` | 距 B1 超過 **60 期**仍未再突破 | **作廢**，轉 `flat`（見 §3.1） |

做空側對稱（下沿、收盤 < 下沿）。

**受測事件是 B2，不是 B1。**

### 3.1 為何需要 60 期上限

2026-08-13 實測顯示，若不設上限，B1→B2 的循環長度 p95 為 100 個交易日
（週 K 為 90 週）。第一次突破後 100 天才二次突破，**已經不是同一個 setup**，
而是另一個 regime。60 期是事前選定的上限，**不得事後掃描**。

### 3.2 時間框架

| 用途 | 頻率 | 依據 |
|---|---|---|
| regime 方向 | **週 K** | 循環長度中位數 19 週，太長不可直接交易，只能定方向 |
| 事件與觀察 | **日 K** | 循環長度中位數 25 個交易日，屬可交易的波段尺度 |

**兩者角色事前固定，不得「兩個都跑再選好看的」。**

## 4. 觀察量

### 4.1 必用超額報酬

```
CAR(h) = R_stock(t → t+h) − R_benchmark(t → t+h)
```

基準見 §8.2：**主檢定為同日合格 universe 的等權總報酬**，
並列報 0050 含息作為次要對照。**不得使用原始報酬**——
本專案已經被原始報酬騙過一次（實測顯示投信連買的 +3.95% 有 86% 只是市場 beta）。

### 4.2 觀察窗

**5 / 10 / 20 / 40 / 60** 個交易日，**全部都要報**，不得只挑好看的。

同時報告 CAR **路徑**，不只終點：單調遞增不回吐，與先漲後吐是兩件事。

### 4.3 成交時點

事件日 t 為訊號日（收盤後才知道）。報酬自 **t+1 開盤**起算，
不得自 t 收盤起算。

## 5. 樣本獨立性

依 PIPELINE §3，本策略屬**連續橫斷面**（實測 2,714/2,812 個交易日都有訊號），
因此：

- **不得**使用事件情境聚合（聚合後只剩 1 個情境，毫無意義）
- 檢定採**組合層 block bootstrap**，block 長度事前固定為 **20 個交易日**
- 必報事件數、相異事件日數、涉及股票數

---

## 6. 驗收與否決

### 通過條件

- 至少 **3 個**觀察窗的 CAR 顯著為正（block bootstrap 下 p < 0.05）
- CAR 路徑不得為「先正後負」的回吐形態
- 事件數 >= 1,000 且涉及股票 >= 200

### 否決條件（任一成立即停）

- 所有觀察窗的 CAR 皆不顯著
- CAR 顯著為正但在 60 日窗回吐至不顯著
- 分年切片後 edge 只存在於單一年份

**否決即記入登記簿並停止，不得加濾網重測。**

## 7. 試驗次數

本文件的 Phase 2 固定為 **2 次試驗**：做多側、做空側。

不得在 Phase 2 掃描 BB 週期、σ 倍數、帶寬門檻、量能倍數或 60 期上限。
那些若要探索，屬 Phase 3 的 plateau 檢查，且須另行登記
（PIPELINE §5：找 plateau 不找 optimum，看到孤峰就丟掉整個因子）。

## 8. 三項裁決（2026-08-13，凍結）

### 8.1 空側：測，但只作為機制對稱性檢驗

Phase 2 是事件研究，**不含成交與成本**，因此「台股放空有借券限制」不影響
這一階段的科學效力。若機制為真（第二次突破代表跟風者耗盡），
**上下沿應呈現對稱的反向**；若只有一側有效，那更像是資料探勘而非機制。

**明文限制**：空側結果只用於檢驗機制對稱性，**不得**據此宣稱可放空操作。
是否可交易屬 Phase 4，且台股借券成本必須另行計入。

### 8.2 基準：主檢定用「同市場等權」，並列報 0050 含息

0050 是市值加權且高度集中於台積電。若事件多發生在中小型股，
用 0050 當基準會把**規模效應**混進訊號效力。

因此：

- **主檢定基準＝同日合格 universe 的等權總報酬**（衡量選股 alpha）
- **次要基準＝0050 含息**（衡量相對實際替代方案的優勢）

兩者**同時報告**，判決以主檢定為準。這不是兩個變體擇一，
是同一個檢定對照兩個參考點，事前固定，不得事後挑好看的那個。

### 8.3 TPEX：納入 H01 Phase 2，H02／H03 限 2018 起

H01 的事件定義只用價量，TPEX 價量自 2015 起完整，因此納入沒有問題。

H02／H03 需要法人買賣超，TPEX 該資料 2018 前不存在且**不得補 0**，
因此那兩個假說若納入 TPEX 須限定 2018 起，並分開報告。
